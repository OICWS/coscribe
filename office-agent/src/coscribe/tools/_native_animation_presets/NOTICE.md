# Vendored PowerPoint animation preset table

`animation_presets.json` is copied, unmodified, from
[`hugohe3/ppt-master`](https://github.com/hugohe3/ppt-master), commit
`6e3ce9c5a3b994a0e223a14a0f7eddf42fd0b9f5` (2026-09-12), at
`skills/ppt-master/scripts/pptx_animation_presets.json`.

Vendored as data, not retyped, because it *is* data worth diffing against
upstream unmodified: 203 real, PowerPoint-authored `<p:cTn>` XML rows (one
per animation preset PowerPoint's own `MsoAnimEffect` enum defines --
entrance/emphasis/exit/motion-path -- generated by exporting from actual
Microsoft PowerPoint 16, per the file's own `source` metadata, not
hand-derived), each keyed by a stable slug (`entrance_fade`,
`path_circle`, ...). Coscribe's `add_pptx_animation` parses one preset's
`row_xml` at call time, renumbers its `<p:cTn>` ids to fit the target
slide's own timing tree, retargets its `<p:spTgt spid="2">` placeholder to
the real shape id, and (when `duration_scalable` is true) scales every
finite duration/delay proportionally to the caller's requested duration --
see `tools/presentations.py`'s `_instantiate_animation_preset_row` and
`_scale_preset_row_duration`. That scaling algorithm is adapted (not
vendored) from this same commit's `pptx_animations.py`
(`_scale_animation_row_duration`/`_row_effective_duration_ms`/
`_ctn_numeric_delay`), ported from `xml.etree.ElementTree` to `lxml` and
credited in a code comment rather than repeated here.
