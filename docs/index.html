    固定工作流Workflows

    Do it once. Rerun it forever.做成一次，以后一键重跑。

    When a conversation gets the job done, save it as a workflow: fixed steps you can review, edit and schedule.对话把活干完后，一键存成工作流：步骤固定，能审、能改、能定时。

    • Same steps, every run每次都是同样的步骤

      Built on LangGraph. Only the inputs change.基于 LangGraph，变的只有输入。

    • Models only where you want them只在需要的步骤调用模型

      This report has no model step: 2 seconds a run, zero tokens.这份日报不调用模型：一次 2 秒，零 token。

    • Stops at the first failure出错就停，不硬写

      A failed check halts the run and says why, instead of shipping a wrong report.检查不通过就停下并写明原因，不会交出一份错的报告。

    模型与权限Models and control

    Any model. Your rules.模型随你选，权限你说了算。

    Claude, GPT and Gemini are built in. DeepSeek, Kimi, GLM, Qwen, Ollama or any OpenAI-compatible service takes just a base URL and a key. Connectors bring in the tools you already use, and you can add your own.Claude、GPT、Gemini 原生支持。DeepSeek、Kimi、GLM、Qwen、Ollama 等任何兼容 OpenAI 的服务，填上地址和 Key 就能用。连接器接入你常用的工具，也可以自己添加。

    Your files stay on your computer. Only what the model reads goes to the provider you picked. With Ollama, nothing leaves the machine.文件始终在你的电脑上。只有模型要读的内容会发给你选的服务商；用 Ollama，数据完全不出本机。

    FAQ

    Before you ask你可能想问

    要付费吗？Does it cost anything?

    coscribe 是 MIT 许可的开源软件，免费使用。你只为自己选的模型服务付费；用 Ollama 跑本地模型则没有 API 费用。coscribe is MIT licensed and free. You pay only for the model service you choose, and nothing if you run a local model with Ollama.

    我的文件会被上传吗？Are my files uploaded anywhere?

    coscribe 没有自己的云端服务。对话中模型需要读的内容，会发给你配置的模型服务商；用 Ollama 的话，全程不离开本机。coscribe has no cloud service of its own. Whatever the model needs to read goes to the provider you configured; with Ollama, nothing leaves your machine.

    它会不经同意就改我的文件吗？Will it change my files without asking?

    取决于你选的模式，见上面的四种模式。无论哪种，写入都只落在工作区和你添加的文件夹里。That depends on the mode you pick, shown above. In every mode, writes stay inside the workspace and the folders you added.

    它能做哪些事？What can it actually make?

    真正的 Word、PPT、Excel 文件：带修订和批注的合同、有图表的汇报、对好账的表格。它也能做数据分析、跑可重复的工作流，写代码的活可以交给代码模块。Real Word, PowerPoint and Excel files: contracts with tracked changes, decks with charts, reconciled spreadsheets. It also analyses data, runs workflows you can repeat, and can hand coding work to the code module.

    支持 Mac 或 Linux 吗？Is there a Mac or Linux version?

    暂时不支持。Not yet.
