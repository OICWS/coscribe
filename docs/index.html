    固定工作流Workflows

    Run it once. Then it runs the same way, every time.跑通一次，以后每次都照这样跑。

    When a conversation gets the job done, Save as workflow turns it into fixed steps you can check, edit and put on a schedule.对话把事情做成后，点 Save as workflow，过程就变成固定步骤：能检查、能修改，还能定时运行。

    • Same steps, same order步骤和顺序不变

      Built on LangGraph. Only the inputs change from run to run.基于 LangGraph，每次运行只换输入。

    • A model only where a step says so写明的步骤才调用模型

      This report has no model step, so a run takes 2 seconds and spends no tokens.这份日报没有模型步骤，跑一次 2 秒，不花 token。

    • Stops where it fails哪步出错就停在哪步

      A failed check ends the run at that step and records why, instead of writing a wrong report.检查不通过就在那一步停下并记下原因，不会写出一份错的报告。

    模型与权限Models and control

    Any model. Your rules.模型随你选，权限由你定。

    coscribe speaks the OpenAI API. Claude, GPT and Gemini are built in; DeepSeek, Kimi, GLM, Ollama or any compatible service is a base URL and a key away. Switch models mid-conversation.兼容 OpenAI API。Claude、GPT、Gemini 原生接入；DeepSeek、Kimi、GLM、Ollama 等兼容服务，填上接口地址和 Key 就能用，对话中途也能换模型。

    Your files stay on your computer. Only what the model reads goes to the provider you chose; with Ollama, nothing leaves the machine.文件留在你的电脑上。只有模型需要读的内容会发给你选的服务商；用 Ollama 的话，什么都不出本机。

    FAQ

    常见问题Questions

    要付费吗？Does it cost anything?

    coscribe 是 MIT 许可的开源软件，免费使用。你只为自己选的模型服务付费；用 Ollama 跑本地模型则没有 API 费用。coscribe is MIT licensed and free. You pay only for the model service you choose, and nothing if you run a local model with Ollama.

    我的文件会被上传吗？Are my files uploaded anywhere?

    coscribe 没有自己的云端服务。对话中模型需要读的内容，会发给你配置的模型服务商；用 Ollama 的话，全程不离开本机。coscribe has no cloud service of its own. Whatever the model needs to read goes to the provider you configured; with Ollama, nothing leaves your machine.

    它会不经同意就改我的文件吗？Will it change my files without asking?

    取决于你选的模式，见上面的四种模式。无论哪种，写入都只落在工作区和你添加的文件夹里。That depends on the mode you pick, shown above. In every mode, writes stay inside the workspace and the folders you added.

    Windows 提示“无法识别的应用”怎么办？Windows warns me when I open it. Is that expected?

    是的。Windows SmartScreen 会对还不常见的新程序弹出提示。点“更多信息”，再点“仍要运行”即可。Yes. SmartScreen warns about new apps it hasn't seen often. Choose More info, then Run anyway.
