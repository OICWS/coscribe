核心特性Features

为普通办公用户设计，而不是程序员Built for office work, not for coding

读写本地文件、生成文档表格和演示稿、连接第三方工具、设置定时任务。coscribe 是你日常的文件和工作流助理。Read and write local files, generate documents, spreadsheets and decks, connect third-party tools, schedule recurring jobs. coscribe is an everyday assistant for your files and workflows.

高质量 Office 文件Polished Office files

PPT、Word、Excel 都是内置工具：可编辑的原生图表、真实可重算的公式、目录与修订痕迹，生成后自动用 LibreOffice 检查文字溢出和文件完整性。PowerPoint, Word and Excel are built-in tools: editable native charts, formulas that really recalculate, tables of contents and tracked changes, with LibreOffice checks for overflow and file integrity.

规划、执行、复核Plan, do, review

Coordinator 把任务拆成可见的清单逐步推进；独立的 Reviewer 能看渲染图，对照你的原始需求复核产出。复杂任务可先用 Plan 模式只出方案。A Coordinator breaks the job into a visible task list; a separate Reviewer that can see rendered pages checks the output against what you asked for. Plan mode drafts a plan before anything is written.

权限与审批Permissions you control

每个工具都有风险等级，内置、MCP、Skill 脚本统一走同一套审批。Manual / Accept Edits / Plan / Auto 四种模式随时切换；文件读写限定在你授权的文件夹。Every tool carries a risk level, and built-in, MCP and Skill tools share one approval flow. Switch between Manual, Accept Edits, Plan and Auto at any time; file access stays inside folders you allow.

固定工作流与定时任务Workflows and schedules

把一次成功的对话固化成固定步骤的工作流，基于 LangGraph 运行，稳定又快；也可以写成提示词任务按计划定时执行。失败时停在出错的那一步，由 AI 帮你复现和修复。Freeze a successful conversation into a fixed-step workflow that runs on LangGraph, fast and repeatable, or schedule a prompt task. A failed run stops at the failing step and AI helps you reproduce and fix it.

MCP、Skill 与 HooksMCP, Skills and Hooks

兼容 Claude Desktop 的 mcpServers 配置，社区现成的 MCP server 直接接入；按需加载的 Skill 和生命周期 Hooks 让你扩展能力而不改核心。Compatible with Claude Desktop's mcpServers config, so community MCP servers plug straight in; on-demand Skills and lifecycle Hooks extend it without touching the core.

内置浏览器与联网搜索Built-in browser and search

桌面版内置浏览器面板，使用你自己的登录状态，你能看着 AI 操作网页并按网站授权；内置网络搜索用于核实事实，下载直接存进工作区。The desktop app has a browser panel that uses your own sign-ins, lets you watch the AI work and grants access per site; built-in web search checks facts, and downloads land in your workspace.

关键设计决策Key design decisions

  • Reflection 交给旁观者。独立的 Reviewer agent 没参与产出，只用只读工具和渲染图来复核。Reflection by an outsider. A separate Reviewer that didn't make the output checks it with read-only tools and rendered images.
  • Office 格式内置，不走 MCP。用成熟、审计充分的 python-docx / openpyxl / python-pptx，而不是让未经审计的第三方进程读写你的文件。Office formats are built in. Mature, well-audited libraries (python-docx, openpyxl, python-pptx) instead of unaudited third-party processes touching your files.
  • 固定工作流运行时不交给模型。步骤和检查条件写死，AI 只在生成和修复时介入，所以稳定又省 token。Fixed workflows don't ask the model. Steps and checks are fixed; AI only helps when creating or repairing them, so runs are stable and cheap.
  • 本地单用户，拒绝过度设计。三档风险等级 + 审批回调，文件存储，不引入数据库和多级权限体系。Local and single-user by design. Three risk levels plus approvals and file storage; no database, no multi-tier permission hierarchy.

快速开始Quick start

几分钟跑起来Up and running in minutes

需要 Python 3.11+、Node.js（构建网页界面），以及任意一家模型的 API Key。You need Python 3.11+, Node.js (to build the web UI) and an API key from any supported model provider.

克隆并安装Clone and install

在 office-agent 目录创建虚拟环境，安装带网页界面的依赖。Create a virtualenv in office-agent and install with the web extras.

配置模型Configure a model

复制 .env.example 为 .env，填入 API Key，并用 provider:model 格式设置默认模型。Copy .env.example to .env, add your API key and set the default model as provider:model.

构建界面并启动Build the UI and launch

首次构建前端后运行 coscribe-web 打开网页界面，或用 coscribe 在终端里对话。Build the frontend once, then run coscribe-web for the web UI or coscribe to chat in the terminal.

bash
# 1. clone & install
$ git clone https://github.com/OICWS/coscribe.git
$ cd coscribe/office-agent
$ python3 -m venv .venv && source .venv/bin/activate
$ pip install -e ".[dev,web]"
$ pip install -U "google-genai>=2.13.0,<2.14.0"

# 2. configure a model
$ cp .env.example .env
#    ANTHROPIC_API_KEY=...  (or OPENAI_ / GEMINI_)
#    COSCRIBE_DEFAULT_MODEL=gemini:gemini-2.5-flash

# 3. build the UI once, then launch
$ (cd frontend && npm install && npm run build)
$ coscribe-web     # web UI
$ coscribe         # or the terminal REPL
