coscribe 是一个运行在你电脑上的开源办公助理。它读取你的表格和文档，规划步骤，做出可编辑的 PPT、Word 和 Excel，再请另一个模型对着渲染出来的页面复核一遍。重要操作之前，它会先问你。 coscribe is an open-source office assistant that runs on your own computer. It reads your spreadsheets and documents, plans the steps, builds editable PowerPoint, Word and Excel files, then has a second model check the rendered pages. It asks before anything important.

工作方式How it works

像一位细心的同事那样做事It works like a careful colleague

每一步都来自上面那次运行。它先列计划，拿不准的地方问你，做完再请另一个模型挑错。Every step here comes from the run above. It plans first, asks when unsure, and has a second model look for mistakes when it's done.

先列计划Plan first

任务拆成清单显示在侧栏，做到哪一步一目了然。复杂的任务可以切到 Plan 模式，先只出方案，你点头后再动手。The task becomes a checklist in the side panel so you can see where it is. For bigger jobs, Plan mode drafts a plan and waits for your OK before changing anything.

需求里没说清楚的地方，它会给出几个具体选项让你挑，而不是自己猜一个。When the request leaves something open, it offers a few concrete options to pick from instead of guessing.

权限Control

放多少手，由你决定You decide how much it does on its own

内置工具、MCP 连接和 Skill 脚本都按风险分级，走同一套审批。四种模式随时切换，对话进行到一半也可以。Built-in tools, MCP connections and Skill scripts all carry a risk level and go through the same approvals. Switch between four modes at any time, even mid-conversation.

Manual每一次修改、运行脚本或对外操作之前都先问你。Asks before every change, script or outside action.
Accept Edits你文件夹里的编辑直接进行；运行代码和对外操作仍然先问。Edits files in your folders without asking; still asks before running code or outside actions.
Plan只做调研、写方案，你批准之前不改任何东西。Researches and writes a plan for you to approve before any change.
Auto由一个审查模型批准常规操作、拦下有风险的操作，不再逐条问你。A reviewer model approves routine actions and blocks risky ones instead of asking you.

只写你给的文件夹Writes only where you allow

文件工具默认只能读写工作区，以及你在对话里添加的文件夹。其他位置需要你在设置里明确加入，可以设为只读。File tools can only read and write the workspace and the folders you add to a conversation. Anything else has to be added in Settings, optionally read-only.

密钥放进系统钥匙串Keys go in your system keychain

API Key 和连接凭据优先存进操作系统的钥匙串；钥匙串不可用时退回本地文件，并把权限收紧到只有你能读。API keys and connection secrets go in the OS keychain when it's available; otherwise they stay in a local file readable only by you.

工作流与定时任务Workflows and schedules

做顺了的事，存成固定步骤Save what worked as fixed steps

一次对话做成功了，点“Save as workflow”，它会把用过的工具调用整理成固定步骤，真实跑一遍测试，再交给你保存。之后按时间表自动运行，每次结果都一样。When a conversation got it right, click "Save as workflow". It turns the tool calls into fixed steps, test-runs them for real, and hands them to you to save. Then it runs on a schedule and does the same thing every time.

  • 运行时不让模型临场决定，只有标明的“模型步骤”才会调用模型，又快又省At run time the model makes no decisions; only steps marked as model steps call it, so runs are fast and cheap
  • 出错就停在出错的那一步，不产出可疑的数据；AI 在新对话里复现原因、起草修改，仍由你保存A failure stops at the failing step instead of producing doubtful data; AI reproduces the cause in a new conversation and drafts a fix for you to save
  • 也可以只写一段指令，做成每次由模型重新执行的提示词任务Or write a plain instruction as a prompt task that the model carries out fresh each time

快速开始Get started

三步跑起来Running in three steps

需要 Python 3.11 以上、Node.js，以及任意一家模型服务的 API Key。You need Python 3.11+, Node.js and an API key from any supported model provider.

  1. 安装Install

    在 office-agent 目录建虚拟环境，装上网页界面需要的依赖。Create a virtualenv in office-agent and install it with the web extras.

  2. 选模型Pick a model

    复制 .env.example 为 .env，填入 API Key，用 服务商:模型 的格式设默认模型。Copy .env.example to .env, add your API key and set the default model as provider:model.

  3. 启动Launch

    首次构建一次前端，然后运行 coscribe-web 打开网页界面，或者用 coscribe 在终端里对话。Build the frontend once, then run coscribe-web for the web UI, or coscribe to chat in the terminal.

bash
# 1. install
$ git clone https://github.com/OICWS/coscribe.git
$ cd coscribe/office-agent
$ python3 -m venv .venv && source .venv/bin/activate
$ pip install -e ".[dev,web]"
$ pip install -U "google-genai>=2.13.0,<2.14.0"

# 2. pick a model: edit .env after copying
$ cp .env.example .env
#   ANTHROPIC_API_KEY=...   (or OPENAI_ / GEMINI_)
#   COSCRIBE_DEFAULT_MODEL=gemini:gemini-2.5-flash

# 3. build the UI once, then launch
$ (cd frontend && npm install && npm run build)
$ coscribe-web

在 Windows 上也可以用 Electron 桌面版，它带内置浏览器面板，安装包由仓库的 GitHub Actions 构建。详见On Windows there is also an Electron desktop app with the built-in browser panel; the installer is built by the repo's GitHub Actions. See office-agent-desktop。.

FAQ

常见问题Questions

要付费吗？Does it cost anything?

coscribe 使用 MIT 许可，完全开源，可以免费使用和修改。你只需要为自己选的模型服务付费；用 Ollama 跑本地模型则没有 API 费用。coscribe is MIT licensed and fully open source. You pay only for the model service you choose, and nothing at all if you run a local model with Ollama.

我的文件会被上传吗？Are my files uploaded anywhere?

coscribe 没有自己的云端服务，文件留在你的电脑上。对话中需要模型阅读的内容，会发送给你配置的模型服务商；用 Ollama 的话，全程不离开本机。coscribe has no cloud service of its own, so your files stay on your computer. Whatever the model needs to read in a conversation goes to the model provider you configured; with Ollama, nothing leaves your machine.

它会不经同意就改我的文件吗？Will it change my files without asking?

取决于你选的模式。Manual 模式下每一次修改都会先问你；Accept Edits 只放行你文件夹里的编辑；Auto 模式由审查模型替你批准常规操作。无论哪种模式，写入都限制在工作区和你添加的文件夹里。That depends on the mode. Manual asks before every change; Accept Edits allows edits in your folders; Auto lets a reviewer model approve routine actions for you. In every mode, writes stay inside the workspace and the folders you added.

需要会写代码吗？Do I need to know how to code?

日常使用不需要，用中文或英文说清楚要做什么就行。目前安装需要照着“快速开始”在终端里敲几行命令。Not for everyday use: describe the task in plain language. For now, installing means running a few commands from the Get started section.

支持 Mac 和 Linux 吗？Does it run on Mac and Linux?

网页界面 coscribe-web 是 Python 程序，可以在 macOS、Linux 和 Windows 上运行。Electron 桌面版和内置浏览器目前只支持 Windows。The web UI, coscribe-web, is a Python app that runs on macOS, Linux and Windows. The Electron desktop app and its built-in browser are Windows only for now.

怎么参与贡献？How can I contribute?

欢迎在 GitHub 上提 Issue 或 Pull Request。设计思路写在仓库根目录的 ARCHITECTURE.md 里，改动之前读一读会很有帮助。Issues and pull requests on GitHub are welcome. The design rationale is in ARCHITECTURE.md at the repo root and is worth reading before a change.
