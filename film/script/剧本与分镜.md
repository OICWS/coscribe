> 片长 120.0 s · 1920×1080 · 30 fps · 全片以 HTML + SVG/Canvas 逐帧渲染
> 主版本：中文（VO、屏显、字幕）。英文版：同一画面，替换 VO 与屏显文案（本文每处均给出 zh / en）。
> 片中所有数据、文件名、公司与项目名称均为**示例**，成片角标注"示例 / Example"。
> 能力对照：本文所有展示的能力均已逐条对照仓库核实（见 §6 的例外清单）。

## 1. 故事一句话与情绪弧线

**Logline**
屏幕上只有一句话。镜头沉到这句话的下面，看见它背后那一整天、一整周的工作被一根蓝线一针一线地做完，再浮上来一份比人做得更扎实的东西。最后一句话，把这一切变成每周一的例行。

**情绪弧线（四拍）**
1. **静** — 空白输入框、一下一下的光标。平静里有一点点疲惫："一句话就能说清楚，却要花掉一个人好几天。"
2. **沉** — 四次下潜，四个幽深、密集、活着的世界。每一次都比上一次更深、更快，像一个人越来越敢于把事情交出去。
3. **见** — 每一次浮上来，都有一个"原来它看见了"的瞬间：重复入账、无依据的数字、第 147 页的矛盾、先红后绿的测试。惊艳不在速度，在它比人更认真。
4. **定** — 整条链凝成一张固定的工作流，一周一周跑过，每次一样。音乐推到最高，然后彻底安静，回到那个空白输入框。

**人物与连续性**
全片只有一个"主角"：**输入框**与从它的光标里长出来的那根**蓝线**（agent 的工作轨迹）。所有深度世界都由这根线牵引；所有成果都沿这根线浮上来；最后它绷直，结晶成工作流。没有人脸，没有人物；只有光标、键声、与第一人称的目光。

```python
def merge_daily(erp: pd.DataFrame, pos: pd.DataFrame, shop: pd.DataFrame) -> pd.DataFrame:
    frames = [normalize(df, src) for df, src in ((erp, "ERP"), (pos, "POS"), (shop, "电商"))]
    merged = pd.concat(frames, ignore_index=True)
    merged["date"] = pd.to_datetime(merged["date"], errors="coerce")       # 2026/10/3 与 2026-10-03 对齐
    merged = merged.dropna(subset=["date", "amount"])                       # 空值不当作 0
    return merged.drop_duplicates(["order_id", "source"])                   # 重复上传只算一次

def flag_anomalies(daily: pd.DataFrame, window: int = 28, k: float = 2.5) -> pd.DataFrame:
    by_store = daily.groupby(["store", "date"])["amount"].sum().unstack("store")
    baseline = by_store.rolling(window, min_periods=7).median()
    return by_store[(by_store / baseline > k) | (by_store < 0)].stack().rename("anomaly").reset_index()
```
